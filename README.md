# A-DEFINATOR-X

A responsive, dependency-free research dashboard prototype designed for GitHub Pages.

## Included prototype

- Nine research areas: Dashboard, Idea Lab, Hypothesis Lab, Mathematics Lab, Science Lab, Simulation Lab, Discovery Lab, Self-Critic, and Research Memory.
- Responsive navigation, research-prompt feedback, capability-roadmap toggle, and module interactions.
- Transparent scope: the interface currently represents 18 prototype workflows out of a planned 420 functions. It does not make automated scientific claims.

## GitHub Pages

This is a static site. In the GitHub repository, open **Settings → Pages**, choose **Deploy from a branch**, then select the `main` branch and `/ (root)` folder.
